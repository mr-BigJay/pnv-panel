# BankRelay ۰٫۴ — عیب‌یابی دریافت و ارسال

این سورس ادامهٔ آرشیو BankRelay-0.3-source.zip است؛ قبلاً در مخزن پنل وجود نداشت.
مسیر فعلی انتقال: پیامک گوشی ← فیلتر بانک/سیم/واریز ← صف محلی ← حساب شخصی بله ← ربات ← پنل.

## نصب و بررسی مشکل
APK نسخه ۰٫۴ را روی ۰٫۳ نصب کنید؛ برنامه را حذف نکنید. بسته و گواهی نسخه تحویلی با ۰٫۳ برابر است؛ نسخه کد ۴ است.
از صفحه اصلی «عیب‌یابی کامل (Diagnose)» و سپس «شروع عیب‌یابی» را بزنید. با «کپی گزارش» نتیجه را ارسال کنید.
گزارش متن SMS، کارت و توکن را نشان نمی‌دهد. فقط زمان‌ها، شمارش‌ها، علت فیلتر و وضعیت مراحل را نشان می‌دهد.
این آزمون حداکثر ۵۰۰ پیام آخر صندوق را فقط برای بررسی می‌خواند؛ پیام را وارد صف نمی‌کند و ارسال ندارد.
درخواست آنلاین بررسی مقصد با نشست ذخیره‌شده به بله فرستاده می‌شود. تنظیمات مقصد را تغییر نمی‌دهد.

## علت‌های مشخص‌شده در کد ۰٫۳
- نمایش مجوز READ_SMS به‌تنهایی اثبات خواندن واقعی نیست؛ اکنون query واقعی اجرا می‌شود.
- اسکن موفق با صفر پیام هیچ رویدادی در گزارش دریافت ایجاد نمی‌کرد. اکنون آخرین نتیجهٔ اسکن جداگانه نمایش داده می‌شود.
- بازیابی فقط از مبدأ فعال‌سازی و حداکثر ۲۴ ساعت اخیر است؛ روشن/خاموش کردن دریافت یا بازیابی مبدأ را تغییر می‌دهد. پیام‌های قبلی خودکار بازپخش نمی‌شوند.
- ستون‌های sub_id/date_sent می‌توانند در پیاده‌سازی صندوق در دسترس نباشند؛ اکنون fallback به ستون‌های اصلی وجود دارد. بدون شناسه سیم، فیلتر سیم خاص همچنان رد می‌کند.
- کار دوره‌ای فعلی به شبکه و زمان‌بندی اندروید وابسته است؛ گزارش این محدودیت و آخرین شروع کار را نشان می‌دهد.
این موارد علت قطعی مشکل گوشی کاربر را اثبات نمی‌کنند؛ گزارش روی همان Poco لازم است.

## مراحل Diagnose
مجوزها و زمان دریافت مستقیم، دریافت/بازیابی، بانک‌ها، خواندن واقعی Inbox، بازه زمانی، فیلترهای فرستنده/سیم/واریز، پیام‌های قبلاً بررسی‌شده، صف و وضعیت ارسال، آخرین اسکن، باتری/محدودیت پس‌زمینه/JobScheduler، شبکه/VPN، نشست و مقصد بله.
خطاهای DNS، TLS، timeout و HTTP دسته‌بندی می‌شوند و متن خام خطا یا پاسخ سرور در گزارش کپی‌شونده قرار نمی‌گیرد.
شماره‌های فیلتر، بازه و تکراری مستقل‌اند؛ یک پیام می‌تواند هم مطابق فیلتر و هم قدیمی باشد.

تأیید ارسال واقعی از «مقصد بله» با پیام آزمایشی موجود انجام می‌شود. Diagnose خود پیام نمی‌فرستد.
رسیدن به بله به معنی خوانده شدن توسط ربات یا تأیید پرداخت نیست؛ اپ هنوز API تأیید پنل ندارد و مرحلهٔ نهایی را «تأیید نشده» گزارش می‌کند.

## اعتبارسنجی
۳۸ بررسی Java: ۷ فیلتر، ۸ پروتکل، ۱۳ تطبیق پیامک، ۱۰ دسته‌بندی خطا و عدم افشای متن حساس.
کامپایل کامل با SDK 35 و Java 17؛ APK با امضای v2/v3 معتبر و گواهی یکسان با ۰٫۳.
تست روی تلفن/شبیه‌ساز یا حساب بله انجام نشده؛ کارکرد عملی OEM و دریافت پس‌زمینه نیازمند گزارش روی گوشی است.

## ساخت
BANKRELAY_SDK باید شامل android-35/android.jar و android-15 (build-tools 35) باشد.
Java 17 لازم است. build_apk.py را اجرا کنید. کلید امضا عمداً در مخزن قرار ندارد؛ اسکریپت مسیر dev-signing/debug.keystore را می‌خواند.
برای به‌روزرسانی نصب قبلی باید همان کلید نگهداری‌شده استفاده شود. کلید جدید جایگزین مناسبی برای آپدیت نصب قبلی نیست.
پس از ساخت، tests/run.sh بررسی‌های Java را اجرا می‌کند.
